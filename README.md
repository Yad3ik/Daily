# Daily PLanner

## Идея проекта
Десктоп приложение, позволяющие в полной мере планировать и отслеживать предстоящие события. Дает возможность визуализировать дедлайны, план на день/неделю. Основные разделы приложения: интерактивный календарь с событиями, TODO List, deadlines. 
Поддерживается облачная база данных, за счет этого все события пользователя, его дедлайны и задачи закрепляются за его аккаунтом и актуальны на любом устройстве.
