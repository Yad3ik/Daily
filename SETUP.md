# Настройка окружения — Daily

Инструкция для локального запуска проекта. Выполняйте шаги **по порядку**.

## Требования


| Компонент  | Ожидание                                                                                                                                                                                            |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Python** | Версия из файла `[.python-version](.python-version)` в корне репозитория (сейчас **3.13.7**). При другой версии `make setup` выведет предупреждение — при возможности используйте указанную версию. |
| **Make**   | GNU Make (`make` в PATH).                                                                                                                                                                           |
| **Git**    | Для клонирования репозитория.                                                                                                                                                                       |


---

## Краткий сценарий

### 1. Первичная настройка

В корне репозитория выполните:

```bash
make setup
```

Команда последовательно выполнит следующие шаги:

1. `**env**` — если файла `.env` ещё нет, создаёт его копированием из `[.env.example](.env.example)`.
2. `**venv**` — создаёт виртуальное окружение в каталоге `.venv/`.
3. `**install**` — обновляет `pip` и устанавливает зависимости из `[requirements.txt](requirements.txt)`.
4. `**check-version**` — сравнивает версию системного `python3` с содержимым `.python-version` и при расхождении выводит предупреждение.

### 2. Переменные окружения

Откройте файл `**.env**` в корне репозитория и подставьте реальные значения вместо заглушек из `.env.example`.


| Переменная   | Описание                             |
| ------------ | ------------------------------------ |
| `DB_URL`     | URL проекта базы данных.             |
| `DB_API_KEY` | Публичный API-ключ для доступа к БД. |


### 3. Запуск приложения

```bash
make up
```

Запускается интерпретатор из `.venv` и скрипт окна входа: `src/front/auth_window/auth_window.py`.

### 4. Запуск unit тестов для backend

```bash
make test
```

Запускается интерпретатор из `.venv` и тесты из папки `src/back/test/`.
Так же выводит покрытие, и не покрытые строки - короче то чему на курсе ТП учили)))
